# Base de connaissance

Modifier les fichiers Markdown dans `docs/`, puis pousser sur la branche `main`. Le serveur reconstruit et publie automatiquement le site après environ une minute.

Prévisualisation locale : installer les dépendances de `requirements.txt` dans un environnement Python, puis lancer `mkdocs serve`.

La configuration et les dépendances du build sur le serveur sont administrées par Ansible. Les fichiers Markdown constituent la source de vérité.
